### 2. AI Recruitment & Candidate Ranking Pipeline

An AI pipeline for extracting structured candidate and job information, semantic retrieval, and candidate reranking.

**Pipeline capabilities**
- CV and Job Description parsing with structured extraction
- NuExtract-based information extraction
- Qwen3 Reranker for relevance reranking
- Sentence Transformers and multilingual embeddings
- Semantic retrieval and candidate matching
- FastAPI-based integration

**Extraction safeguards**
- Internships remain separate from professional employment
- Academic projects remain separate from employment
- Languages are extracted only when explicitly stated
- Education levels are normalized consistently
- Missing candidate information is not inferred
- LLM extraction is constrained to reduce hallucinated information

**Public portfolio version in preparation.**
